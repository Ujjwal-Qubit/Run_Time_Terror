APP LOGO ASSET PACK

Source artwork: user-provided logo. No redesign or added aesthetics.
The artwork was only upscaled and exported into common application formats/sizes.

Primary files:
- app_logo.svg — SVG container with the logo on black
- app_logo_transparent.svg — SVG container with transparent background
- app_logo_4096.png — 4096x4096 PNG on black
- app_logo_transparent_4096.png — 4096x4096 PNG with background removed
- app_logo.pdf — PDF export on black
- favicon.ico — common favicon sizes
- app_icon_* — common app/web icon sizes

Note: the SVG files are pixel-faithful SVG containers embedding the high-resolution PNG artwork; this preserves the supplied logo exactly rather than redrawing it and changing its geometry.
